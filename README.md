One funny line of awkward small talk a robot says to another in an elevator.

## Entry

> I ran a diagnostic on this silence. Results: 98% awkward, 2% elevator music, and 100% me pretending I have somewhere to be on floor 12.

## How it works

`main.ts` (Node 22 stdlib only) validates the line against the gate — a single
line, 1–200 characters, not only whitespace — then writes it to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). It never
removes the output directory itself, only creates it if missing.
